`LTTNG_TERM_COLOR`::
    Controls when to emit terminal SGR codes in the output.
+
The `NO_COLOR` environment variable overrides this.
+
One of:
+
--
`auto` (default)::
    Only emit SGR codes when the standard output is connected to a
    color-capable terminal, or when the `FORCE_COLOR` environment
    variable is set and not empty.

`always`::
    Always emit SGR codes.

`never`::
    Never emit SGR codes.
--

`NO_COLOR`::
    If set and not empty, then it's equivalent to setting
    `LTTNG_TERM_COLOR` to `never`.
+
See https://no-color.org/[NO_COLOR] to learn more.

`FORCE_COLOR`::
    If set and not empty, then emit SGR codes even when the output
    isn't connected to a color-capable terminal.
+
This environment variable only applies when `LTTNG_TERM_COLOR` is
`auto` and the `NO_COLOR` environment variable isn't set.
+
See https://force-color.org/[FORCE_COLOR] to learn more.
